# 今天 · 小程序原型（本地运行）

纯前端、无后端、无构建，所有记录保存在浏览器 localStorage。

## 本地启动

```bash
cd "/Users/fay/Desktop/探索 2"
./start.sh          # 或 python3 -m http.server 8080
```

然后打开 http://localhost:8080

- 桌面浏览器：页面居中显示为手机壳，建议用 Chrome（长按「记一下」语音需要 Web Speech API）。
- 手机预览：同一 Wi‑Fi 下访问 `http://<电脑IP>:8080`（语音在非 localhost 的 http 下会被浏览器禁用，文字/拍照不受影响）。

## 页面

| Tab | 内容 |
| --- | --- |
| 🏠 今天 | 日期 / 节气 · 「＋ 记一下」（点击选择、长按说话）· 今日时间轴 · 树的彩蛋 · 今日一问 |
| 🌳 我的树 | 一次记录 = 一片叶子，一张照片 = 一朵花，一次心情 = 一颗果 |
| 🌙 梦境 | 所有「记个梦」的归档 |
| 📖 我的一年 | 年度统计、十二个月、四季、《我的 2026》占位 |

## 「记一下」万能捕捉器

全屏页，三个动作：**扔进来 → AI 帮你整理 → 留下来**。

- 进入即可写；🎙 按住说一说（松开即完成）；📷 / 🌙 / 😊 只是快捷入口，不先选类型
- 照片：选完直接留下，不强迫写描述
- 梦境：「还记得刚才的梦吗？」→ 🌙 梦境记录卡（梦中出现 / 醒来时的感觉）
- 心情：十个词一选（含「说不清」），不是量表
- 「完成」即留下，随后看到**记录完成卡**（下）
- **AI 不抢戏**：只有文本里出现「帮我想想 / 你觉得呢 / 我也不知道为什么」等邀请时，才出现一次对话入口

## 记录完成卡（原始的我 + AI 轻轻整理后的我）

- 顶部：`2026.09.04 · 14:32` / `白露前 · 秋`，「查看当时 →」展开 🕰 🌿 📍 ❤️ 👤 📷
- **原话原样保留**（只收空白、补句号），大号宋体加引号
- AI 最多三层：主题 · 状态（有转折时写成 `烦躁 → 放松`）· 关键词，到此为止
- 🌿 关联：过去 90 天主题相同的记录，按日期列出原话；连续 ≥2 周出现同主题时加一句「你已经连续 N 周记录了类似的想法。」
- 梦境卡：换视觉语言，「梦里出现」「醒来时」，以及「🌙 留给未来的你：这是你今年记录的第 N 个「寻找」主题的梦。」不解梦
- 照片卡：照片在上，`今日状态 紧绷 → 松下来`
- 底部：`✓ 已经替你留下`；「未来的你，会看到今天的你。」只在第一条、当天第一条、第 7/30/100/365 条或小概率出现
- 隐私：**不关联这条记录** / **不希望 AI 分析这类内容**（按主题静音，之后同类内容只保留原话）
- 时间轴里点开旧记录，看到的是同一张卡

## 「AI 整理」

MVP 阶段不接模型，`app.js` 里的 `tidy()` 用规则默默建立结构：时间段、主题、状态、地点、关键词、与当天其他记录的关联、梦中元素。
完整结构存在 `record.tidy`，用户只看到很轻的一层。之后接入模型时，只需替换 `tidy()` 一处。

## 节气

`app.js` 中 `TERMS` 表为 2026 年北京时间节气日期，其他年份沿用作近似。
